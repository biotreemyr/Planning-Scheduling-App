# Bio Tree Scheduler Roadmap

## Phase 1 Project Foundation

The repository opens locally, documentation exists, the data model is defined, and the basic operational layout appears.

## Phase 2 Master Data

Products, work centres, machines, employees, and customers can be created, edited, searched, and deactivated.

## Phase 3 Planning Layer

The planner can create a production plan and add plan lines by date, product, quantity, priority, order reference, and notes.

## Phase 4 Scheduling Layer

Production can create schedule entries from plan lines and assign work centre, machine, start, end, status, and notes.

## Phase 5 Conflict Checks And Reports

Machine overlaps are flagged, unscheduled plan lines are visible, and weekly load can be reviewed by work centre.

## Phase 6 Pilot Hardening

Pilot feedback is grouped into Must Fix, Useful Later, and Not For MVP. Import, export, audit trail, and migration decisions are refined.
